# Feature Description: actions

## Goal

Execute combat actions with deterministic rules, budget enforcement, and auditable outcomes.

## Core Features

1. Authorization and ownership checks before execution.
2. Action economy budget controls (action, bonus, reaction, movement).
3. Typed outcome envelopes for attack, save, heal, and effects.
4. Reason-coded denial outcomes for invalid action paths.

## User Outcomes

1. No hidden or silent action failures.
2. Turn flow stays consistent and enforceable.
3. Combat outcome data is replayable and testable.
