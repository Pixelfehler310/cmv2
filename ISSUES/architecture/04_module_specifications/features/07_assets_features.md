# Feature Description: assets

## Goal

Manage media assets with explicit ownership, linkage, and archival rules.

## Core Features

1. Asset registration and metadata validation.
2. Scene linkage and layered rendering references.
3. Owner and DM policy gates for modify/archive actions.
4. Retention-based archival and purge lifecycle.

## User Outcomes

1. Media ownership and access are enforceable.
2. Scene assets remain consistent and traceable.
3. Archival prevents accidental destructive loss.
