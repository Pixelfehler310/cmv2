# Feature Description: shared

## Goal

Provide common contract primitives for reason codes, decisions, envelopes, and invariant checks.

## Core Features

1. Central reason-code registry and taxonomy.
2. Standardized error and denial envelope formats.
3. Shared policy-decision and context-wrapping primitives.
4. Reusable invariant validation catalog.

## User Outcomes

1. Cross-module semantics stay aligned.
2. Error behavior is consistent and testable.
3. Validation logic is reusable and deterministic.
