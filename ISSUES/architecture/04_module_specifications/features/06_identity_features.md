# Feature Description: identity

## Goal

Provide consistent authentication, session context, and entitlement evaluation across all modules.

## Core Features

1. User and session lifecycle contracts.
2. Campaign entitlement grant and revoke pathways.
3. Effective identity resolution with delegation awareness.
4. Permission snapshot generation for downstream checks.

## User Outcomes

1. Identity and role behavior is deterministic.
2. Authorization decisions are explainable.
3. Session context remains coherent across transport and services.
