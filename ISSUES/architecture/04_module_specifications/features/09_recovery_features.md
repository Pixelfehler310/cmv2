# Feature Description: recovery

## Goal

Detect and recover projection drift with deterministic replay and checkpoint workflows.

## Core Features

1. Drift detection and gap classification.
2. Snapshot and replay restoration paths.
3. Checkpoint verification and retention management.
4. Recovery status tracking with explicit outcomes.

## User Outcomes

1. State divergence is visible and actionable.
2. Recovery operations are repeatable and validated.
3. Projection integrity is maintained after failures.
